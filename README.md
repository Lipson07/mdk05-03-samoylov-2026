# МДК.05.03 — Тестирование информационных систем

Работы Самойлова Артема Сергеевича, группа 4ИСП9-45. Основание — индивидуальный график МДК.05.03 и [перечень практик преподавателя](https://github.com/softboxdev/test_methodologies/blob/main/program_practice.md).

| Задание | Содержимое |
|---|---|
| № 1 | Чек-лист, пять тест-кейсов, баг-репорт о некорректной проверке email |
| № 2 | Разбор HTTP-запроса и ответа локального учебного сервиса |
| № 3 | Позитивные и негативные проверки регистрации и входа |

Объект проверки — собственный учебный проект [«Конференции.РФ»](https://github.com/Lipson07/mdk09-01-samoylov-2026). Проверки выполнялись на временной SQLite-базе. Персональные данные и реальные учётные записи не использовались. Фактические ответы сохранены в `evidence/verification.json`; скрипт `scripts/verify_portal.py` повторяет проверку при наличии локальной копии проекта МДК.09.01.

Дефект зафиксирован 28.10.2026: сервер принимает `bad@` как email, хотя ожидается полноценный адрес. Остальные 8 из 9 автоматизированных HTTP-проверок прошли. Проверка выполнялась программным HTTP-клиентом; снимок вкладки DevTools не создавался.
